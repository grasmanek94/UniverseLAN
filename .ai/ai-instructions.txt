Detailed information needed for task:
UniverseLAN is a GOG Galaxy wrapper DLL and server backend which re-implements the same public interface that GOG Galaxy library exposes. GOG Galaxy is used in games and UniverseLAN is a drop-in replacement so it can take over GOG Galaxy functionality, such as multiplayer and lobbies.
The same functions that perform "something" on the internet/GOG backend, are in UniverseLAN performed against its' own server software (SRC: Server, Shared\, Shared\Networtking, Shared\Networking\Messages).

All GOG Galaxy versions are implemented, these are split into a common codebase and version specific projects defined in CMake.
Output by default go to ROOT\bin\<version>\ or ROOT\bin\tests\<version>\
Outputs are: Galaxy64.dll Galaxy.dll (dll are sometimes prefixed with RED), UniverseLANServer.exe UniverseLANServer64.exe
The project uses CMake.
ROOT\Source\DLLs\<version>\ contains:
- galaxy: the public SDK headers from GOG itself
- gog: the official .dll and .lib files from GOG itself
- x64 and x86: .rc files for the projects dll files and .def files
- Empty .cxx file that indicates if this is a Galaxy Factory enabled build or not

The UniverseLAN implementation is located inside SRC directory inside these directories:
- Client (has feature ifdefs) and Client_NoVer (generic library for all versions)
- Shared (has feature ifdefs) and Shared_NoVer (generic) are libraries for both server and client
- Server has version specific server projects
- Features are defined through CMake, inside SRC\galaxy_sdk_features.cmake, this cmake file makes sure that each version has the correct #define GALAXY_BUILD_FEATURE_<feature name> = 0/1
- When generating/configuring the project(s) with cmake, if it's not necessary to create all version variants, limit the versions with, for example "-D LIMIT_VERSIONS="1.139.2"", speeds up complete project build times dramatically.
